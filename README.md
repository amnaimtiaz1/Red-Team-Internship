## Week 01 — Cybersecurity Fundamentals & Security Concepts

**Covered Topics**
- Cybersecurity Fundamentals
- CIA Triad (Confidentiality, Integrity, Availability)
- Real-World Cyberattacks
- Cybersecurity Tools
- Secure Home Network Design
- Daily Responsibilities of a Cybersecurity Analyst

---

## Week 02 — Computer Networking Fundamentals

**Covered Topics**
- Network Information (IPv4 Address, MAC Address, Default Gateway)
- Basic Networking Commands
  - `ipconfig /all`
  - `ping`
  - `tracert`
  - `nslookup`
  - `arp -a`
- Router vs. Switch
- IPv4 vs. IPv6
- OSI Model

---

## Week 03 — Network Reconnaissance & Web Enumeration

**Covered Topics**
- Common Network Protocols & Default Port Numbers (TCP/UDP)
- HTTP vs. HTTPS — SSL/TLS Verification & Redirection Analysis
- Network Reconnaissance in Kali Linux using **Ping** and **Nmap**
- The Complete Lifecycle of a Web Request (DNS Lookup → TCP Handshake → TLS Handshake → HTTP Request/Response → Page Rendering)
- Networking Protocol Cheat Sheet — Ports, Risks & Secure Alternatives
- Web Enumeration using **WhatWeb** and **Whois**

**Tools Used:** `Kali Linux` · `Nmap` · `WhatWeb` · `Whois` · `Ping`
